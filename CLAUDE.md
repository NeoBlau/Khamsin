# Хамсин — заметки для работы над кодом

Курьерский симулятор по пустыне на Godot 4.5.1. Основная платформа — macOS
(Metal). Общее описание в README.md, здесь только то, что нужно знать, прежде
чем что-то менять.

## Порядок работы

```bash
tools/test.sh                  # обязательно перед каждым коммитом
tools/test.sh --filter tire    # часть тестов
```

`tools/test.sh` сам делает `--import`. **Это не формальность**: после
добавления нового `class_name` Godot не видит его до импорта, и половина
проекта «не компилируется» без единой настоящей ошибки.

Скрипты проверяются только внутри поднятого дерева сцены. `godot --check-only`
здесь бесполезен: он не знает про автолоады, и каждое обращение к `Config` или
`EventBus` выглядит для него ошибкой.

## Что сломается тихо

Каждый пункт ниже — реальный баг из истории проекта. Все закрыты тестами, но
их легко вернуть.

- **Обход треугольников.** Лицевая грань в Godot — по часовой стрелке.
  Обратный порядок не даёт ни ошибки, ни предупреждения: поверхность просто
  перестаёт рисоваться, и в кадре остаются торчать юбки чанков, которые легко
  принять за рельеф. Соглашение проверяется по эталонному `PlaneMesh`.
- **`return` в fragment-шейдере** запрещён. Шейдер с ним не собирается, и
  материал молча перестаёт рисоваться.
- **Точность шума в шейдерах.** Карта двадцать километров: `fract(p * 123.45)`
  на координатах в тысячи метров вырождается в константу. Решётку заворачивать
  в период, множители держать меньше единицы.
- **Высотный туман** в Godot сгущается *ниже* `fog_height`, а не выше.
- **Демпфирование скорости** у `RigidBody3D` включено по умолчанию (0.1).
  Для машины это несколько килоньютонов встречной силы: сопротивление здесь
  считается явно, поэтому демпфирование выключено насовсем.
- **Приведённая инерция.** Момент через передачу 25:1 приходит на колесо
  умноженным в двадцать пять раз. Без инерции двигателя, приведённой к колесу,
  петля обратной связи идёт вразнос и колёса начинают крутиться назад.
- **Решения по оборотам двигателя.** При разомкнутом сцеплении и при буксующем
  колесе двигатель свободно раскручивается до отсечки. Всё, что зависит от
  «сколько сейчас оборотов», надо считать от скорости колёс.
- **Многострочные лямбды внутри литералов массивов** ломают разбор GDScript.
  Выносите лямбду в переменную.
- **Целые константы** больше `int64.max` (`0x9E3779B97F4A7C15`) GDScript не
  принимает — писать знаковым десятичным.
- **`b | 1`** как способ сделать множитель нечётным склеивает 0 с 1 и 2 с 3.
  Для перемешивания брать `b * 2 + 1`.

## Правила проекта

- Ни одного магического числа в коде машины и мира: всё в `data/*.json` и в
  `src/core/config.gd`.
- Ни одной случайности мимо `Rng`. Мир, доска заказов и погода выводятся из
  сида, поэтому сейв хранит число, а не состояние.
- Рельеф — чистая функция координат. Её зовут генератор меша, генератор
  коллизии, маршруты и запрос «что под колесом»; расхождению взяться неоткуда,
  и так должно остаться.
- Интерфейс собирается кодом (`src/ui/widgets.gd`), сцены экранов — пустые
  обёртки со скриптом.
- Условия и последствия в сюжете — фиксированный набор ключей, а не язык
  внутри JSON. Неизвестный ключ должен ругаться, а не молчать.

## Инструменты

```bash
# стенд телеметрии: разгон, тормозной путь, давление в шинах, предельный уклон
godot --headless --path games/khamsin res://tools/bench_vehicle.tscn

# снимок мира без запуска игры руками
xvfb-run -a godot --path games/khamsin --rendering-driver vulkan \
  --resolution 1280x720 res://tools/screenshot.tscn -- \
  --out /tmp/shot.png --hour 8.5 --drive 6 --screen contracts
```

Стенд — не тест: он измеряет, а не утверждает. Пороговые проверки живут в
`tests/`. При этом именно он нашёл четыре бага трансмиссии, которых не видно
ни в коде, ни в тестах: числа врут заметнее, чем логика.
